# Healthcare Data Analysis & Machine Learning Project

## Project Overview

This Project focuses on analyzing a healthcare using **Python, Exploratory Data Analysis(EDA), Data Visualization, Correlation Analysis,
Machine Learning, and Power BI**

the Project follows an end-to-end data science workflow, starting from data loading and cleaning, followed by exploratory analysis and visualization, and finally building a **Random Forest classification model** to predict medical-condition categories.

A **Power BI interactive dashboard** was also created to present important healthcare insights in an easy-to-understand format.

**Note:** The healthcare dataset used in this project is synthetic/dummy data intended for educational and data-analysis practice. It should not be used for clinical diagnosis or medical decision-making.

---

## Project Objectives

The main objectives of this project are :
- Understand and explore the healthcare dataset.
- Perform data cleaning and preprocessing.
- Analyze patient demographics.
- Analyze medical conditions and admission types.
- Study healthcare billing patterns.
- Perform correlation analysis.
- Visualize important healthcare trends.
- Build a multi-class classification model.
- Create an interactive Power BI healthcare dashboard .
